# Mahasri K T — Portfolio
Open `index.html` in a browser. No build step.

- `index.html`, `css/style.css`, `js/script.js` — the portfolio
- `demo/` — three sample demos (frontend only, made-up data, labelled as samples): CareerGap AI, APART, UPI Fraud Detection
- `js/fx.js` + `css/fx.css` — 3D/futuristic effects layer (delete both and their tags in index.html to remove)
- `js/three.min.js` — Three.js, bundled locally
- `images/profile-shoulders.png` — head-and-shoulders cutout of the supplied photo
- `certificates/` — real certificate PDFs plus preview images
- `assets/MahasriRESUME.pdf` — resume

## Adding real links
In `js/script.js`, replace `YOUR_GITHUB_REPOSITORY_URL` in `REPOS` with each repository URL. Until then the GitHub buttons open https://github.com/maha-6380.
When a project is deployed, change the Live Demo `href` in `index.html` and remove the "Sample" label.
